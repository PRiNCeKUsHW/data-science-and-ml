# Data Science and Machine Learning Practice

My collection of **Jupyter notebooks for learning data science and machine learning in Python**, from Python basics through NumPy, Pandas, visualization, SQL and core ML algorithms built from scratch.

## Contents

### Python foundations

| Notebook | Topic |
|----------|-------|
| `oops.ipynb` | Object-oriented programming in Python |
| `multidimensional list .ipynb` | Nested lists |
| `Working with file/` | Reading and writing files |

### Data handling

| Notebook | Topic |
|----------|-------|
| `numpy.ipynb` | NumPy arrays and operations |
| `pandas/pandas.ipynb` | Pandas DataFrames (Iris dataset) |
| `pandas/Assingment .ipynb` | Pandas exercises |
| `file/` | Analysis of an Amazon jobs dataset |
| `sql/` | SQL queries from Python with SQLite (school, IMDB and employee databases) |

### Visualization

| Notebook | Topic |
|----------|-------|
| `matplotlib.ipynb` | Matplotlib basics |
| `seaborn.ipynb` | Seaborn plots |
| `Graph/` | Charts and an assignment on the Amazon jobs dataset |

### Machine learning (`ML/` and `machine_learning.ipynb`)

| Notebook | Topic |
|----------|-------|
| `gradient decendent and lr basic.ipynb` | Gradient descent and linear regression basics |
| `linear reg with formula and assingment.ipynb` | Linear regression from the formula |
| `linear reg with sklearn multi variable.ipynb` | Multivariable linear regression with scikit-learn |
| `Project gradient decendent.ipynb` | Gradient descent project |
| `Gadient decendent Bostan dataset/` | Gradient descent on the Boston housing dataset |
| `logestic regression breast cancer.ipynb` | Logistic regression on the breast cancer dataset |
| `Logestic regression/` | Logistic regression on the Titanic dataset |

## Tech Stack

- Python 3
- NumPy, Pandas
- Matplotlib, Seaborn
- scikit-learn
- SQLite
- Jupyter Notebook

## How to Use

```bash
git clone https://github.com/PRiNCeKUsHW/data-science-and-ml.git
cd data-science-and-ml
pip install numpy pandas matplotlib seaborn scikit-learn jupyter
jupyter notebook
```

Open any notebook from the browser. Datasets are stored next to the notebooks that use them.
